# 3. 更新日志行内 Markdown 渲染：支持面、安全契约与链接/图片落地

## 背景

面板第 02 章此前把 `CHANGELOG.md` 条目**原样**显示：反引号、`**`、`[文本](url)` 与裸 URL 都当普通字符画出来。野外取样显示正文里最密的就是这些行内符号（行内代码 4914 处／81 份、粗体 4742／26、绝对链接 6286、裸 URL 6671），所以“原样显示”等于把作者写的排版意图全丢掉。约束：日志来自第三方包、内容不可信；面板正文宽约 400–460px；本包零运行期依赖；`renderChangelogHTML` 的输出被集成方直接用（形状不能乱动）；两主题同一份 DOM、只换 CSS。

## 决策

### 1. 手写行内渲染，不引 Markdown 库

零依赖纪律 + 只要行内子集 + 必须“永不抛错、永不直通 HTML”。新导出纯函数 `renderChangelogInline(text)`（`src/changelog.ts`），支持面常量 `CHANGELOG_MD_INLINE`。

支持面（按野外命中定，不按规范全量）：`` `code` ``、`**strong**`、`*em*`、`~~del~~`、`[文本](http(s))`、`<http(s)…>`、裸 URL、`![alt](url)` 占位。**不做**：表格、脚注、emoji 短码、定义列表、标题锚点、`<details>`（野外 0 例，且 400px 宽做表格必然难看）。

### 2. 安全契约（三条硬线）

- **HTML 永不直通**：一切文本先转义再拼标签。野外真反例：`dsh-im-companion` 的日志里有 `dsh-im<channel>`，直通渲染会把它吃掉或破坏结构。
- **只认 http/https**：`javascript:`／`data:`／`file:`／相对路径一律按字面文本；渲染期白名单 + 点击期再筛一次（纵深防御）。
- **未闭合标记按字面输出**：渲染器不猜不补，输出永远标签配平（截断是真会切在 `` ` `` 或 `**` 中间的）。

### 3. 解析形状冻结，渲染层独自变化

`ChangelogEntry.sections` 仍是**原文**字符串数组，`counts`、字符截断（64 KiB 全文／500 字单条／每类 200 条）与解析时机一字不全改；0.14.0 里只有 `renderChangelogItem` 的输出变了。理由：集成方（如 dsh-prompt／dsh-mattpocock-skills-deck）读 `parseChangelog` 的结果，改形状就是破坏性变更，而当时的需求只要“显示得漂亮”。

截断口径同理不动数值：**截断仍在解析期按字符切**，渲染期做两件兜底——悬空标记串（渲染后可见文本里仍是裸 `**`／`` ` ``）剥掉；配平的一对照渲染。

**修订（0.15.0，`#116` 返工）**：这一条被自己推翻了一半。“冻结”只保住了**数组与字段名**（`sections: Record<ChangelogCategory, string[]>`、`counts`），保不住**条目内部的形状**：块级构造（嵌套层次／围栏代码块／引用块）在单行拍平的条目里根本不可恢复——0.14.0 结票后对真实管线实测确认了这一点（见下节）。因此 0.15.0 起：

- 单个条目可含 `\n`（嵌套子条目、围栏、引用按行留在一起）；**这是破坏性变更**，已写进 CHANGELOG 与 README §5.8 的迁移说明。
- 嵌套子条目不再各占一条：`sections` 长度与 `counts` 只按**父条目**算（决策：层次比条数重要，且 counts 的用途是“共 M 条，仅显示前 N 条”的提示，父条目数才是用户认的“条”）。
- 单条 500 字截断改为按行累加，装不下的行不再硬塞碎屑。

教训记在这里：**“输出形状冻结”这种决策必须写清冻结的粒度**——“数组与字段名不变”与“条目内部不变”是两回事，含糊的冻结会在下一轮返工里被当成“反正没改公开 API”。

**修订（0.16.0，保真轮，`#116`）**：粒度再收一次——连“字段名不变”也不足以保住“内容不丢”。0.15.0 之后重跑的保真审计（`.tmp/audit-fidelity-v2.mjs`，本机 88 份 CHANGELOG）给出的数字是：**91.9% 的列表项行看不到**，插件语料只有 73.3% 的内容行可见，`dsh-im-companion` 的 126 条旧节整节消失。根因不是渲染，而是**解析层把“认不出来”当成“丢掉”**：非六类小节名的整节内容、版本节下没有 `###` 的裸条目、`## 1.0` 这种两段版本号、H1/H4/setext 版本标题、顶格段落/引用/围栏，全部静默消失。

所以 0.16.0 把这一条的判据从「形状冻结」换成 **「无未声明丢失」**：

- **未知小节名不再丢内容**：非六类小节名 → `ChangelogEntry.otherSections: Array<{ title, items, count }>`（标题按作者原文保留，`renderChangelogHTML` 照画）。这是**破坏性新增字段**，写进 CHANGELOG 与 README §5.8；只读 `sections` 的集成方零改动。
- **版本身份放宽**：1–4 级任意标题 + setext 下划线 + 标题任意位置的版本号；两段版本号（`## 1.0`）也是合法版本节。“像版本节”的闸门仍在（`# Changelog`／`## License`／`### 修复 1.2 的 bug` 不会被误当版本节——两段号必须标题里除它只剩装饰）。
- **顶格内容不再丢**：顶格段落、顶格引用、顶格围栏都收进条目（此前静默丢弃，围栏内容整段丢）。空行是段落边界：顶格块另起一条，缩进行照旧并进当前条目。
- **截断必须出声**：文件超 64 KiB、版本被截都在面板补一行说明（`changelog.truncated.file` / `changelog.truncated.versions`）；`parseChangelogReport(markdown)` 把 `truncation` 作为数据交出来（`parseChangelog` 仍是 `.entries` 薄封装）。
- **诊断码随事实改**：`E_CATEGORY` 下线（非六类不再丢内容）→ `W_CATEGORY_OTHER`（提示）；新增 `E_BULLET_ORPHAN`（版本节之外的条目，其内容确实进不了任何版本节——这是**唯一**还允许丢内容的入口，且必须报 Error）；`E_VERSION_TITLE` 收窄为“像版本标题却取不出号”（`## 1`、`## 2026-10-14`）。

二审教训：**“冻结”这种决策，最后必须落到“哪些信息可以丢、丢了怎么让人看见”**——只写“字段不变”会把解析层的丢字藏在契约的缝里，等下一轮审计才发现。验收口径也一并改成可测量的三条：`未声明丢失内容行 = 0`、`幻影版本 = 0`、内容行覆盖率 ≥ 95%（用独立于被测解析器的小尺子在**原始文本**上分结构行/内容行来量，见 `.tmp/audit-fidelity-v2.mjs`）。

### 4. 图片只出占位，永不联网

`![alt](url)` → `<span class="dsh-upd-md-img" data-src="…">alt</span>`，**不产出 `<img>`、不发请求**。理由：日志来自第三方包，联网取图等于把用户 IP／在线状态／来源信息送给任意作者；离线与防盗链也都会让图变破框；宿主插件侧没有取图/代理能力（见 #111 取证），web 外壳认证后的 CSP 头**至今未验证**（#111 §6 E4）——占位策略对 CSP 两种结果都成立，所以不必等它。alt 为空时退回显示地址。

### 5. 链接落地：锚 + 可选 `openLink`，不新增宿主电话

渲染 `<a class="dsh-upd-md-link" data-openlink="1" href target="_blank" rel="noopener noreferrer">`；点击走面板**现有唯一**的 `onClick` 委派里新加的一枝 → `preventDefault()` → `options.openLink ?? defaultOpenLink`（`window.open(url,"_blank","noopener,noreferrer")`）。桌面宿主的 `setWindowOpenHandler` 会把 http/https 交给 `shell.openExternal`（#111 取证：`asar:lib/main.js:11109-11112`），web 宿主则是普通新标签页。**没有第五个电话**：宿主侧零改动，README 第 17 行冻结的四电话表不动。

### 6. 双主题同一份 DOM，只换 CSS

最小可用样式进 `UPDATE_PANEL_CSS`（代码底色、链接色、虚线图片占位、代码块/引用块/列表），档案卷 `UPDATE_PANEL_ARCHIVE_CSS` 只换肤（纸色底、朱红细底线链接、`catname` 隐藏与 `li::before` 前缀照旧）。全部走现有 token，第三方 `themeTokens` 覆盖即生效；不新增配色体系。

**0.15.0 补注（屏幕复核发现的皮肤缺陷）**：档案卷用 CSS `::before` 给每条补红字类名前缀（#102 的原型设计），这在新的嵌套列表下会出两处难看——

1. 选择器 `… ul li::before` 会钻进 `<ul class="dsh-upd-md-list">` 的子项，于是每个子项都被补上「Added ·」，有序子项更是变成「1. Added · 先跑门禁」。收紧为 `… > ul > li…`（直接子级）即只作用于顶层条目。
2. 正文自己以类名开头时（真实 changelog 常见 `**Added** · …`、中文 `新增 · …`）再补前缀就成了「Added · Added · …」。CSS 认不出文本，所以由 `renderChangelogItem` 在条目 HTML 上标 `data-cat-lead="1"`（纯内容事实，不含主题语义），皮肤用 `:not([data-cat-lead])` 跳过；判定只认「类名 + 边界」，`Addendum`／`新增功能` 之类不算。

性质说明：`data-cat-lead` 只被档案卷皮肤读，默认主题的 CSS 不看它，所以「一套 DOM 两套皮肤」没破——DOM 里放的是内容事实，皮肤决定怎么用。

教训：给**文本节点**加装饰性前缀（`::before`）时，选择器必须限定到「作者写的那些顶层条目」；一旦下游出现嵌套结构，随手写的 `ul li` 会连子孙一起染色。

## 备选与否决

- **引 markdown-it / marked 等库**：否决——本包运行期依赖只许一个 `dsh-log`（ADR-0005 刚立的纪律），再加一个 Markdown 库要翻两次纪律；且库还带来 HTML 直通/危险 URL 的第二套 sanitizer 面。手写子集在真实语料上的覆盖率见下节（插件语料 98.5%），“全面 CommonMark 合规”至今没有真实需求（野外表格/脚注/任务清单 0 例）。
- **大爆炸三段式管线（`scan` → `parse`（判别联合 IR）→ `render`）**：0.16.0 评估后否决——现有 IR（行数组 + 缩进 + 围栏 + 小节/版本节）在本机 88 份语料上够用，换成完整 AST 与判别联合**不改变任何用户可见指标**，却把 1053 例测试的全部门槛抬高一遍；先做“无未声明丢失”的机械改造，等真出现表达力不够的构造再谈管线重写。
- **只测“漏”不测“造”**：否决——验收同时要证伪“幻影版本”（每个产出版本节必须有源行的版本号 token 支撑）。这次审计脚本第一版尺子自己写错过（把行首 `-` 带进比较键，导致 38/91 假红），教训是**尺子本身也要被验证**。
- **HTML 直通（信任作者）**：否决——`dsh-im<channel>` 与 `<script>` 类输入会让面板结构被吃掉；README 的信任模型是“日志只显示、不执行”。
- **直接 `<img src>` 取图**：否决——隐私、离线、防盗链三条都站不住，且 CSP 未验证。
- **经宿主代理取图**：否决——宿主插件侧没有这个能力，为此加第五个电话超出本需求。
- **表格渲染**：否决——野外 0 例，400px 宽必然难看；表格原样文本显示。
- **渲染期做结构化解析产物**：0.14.0 否决——会动公开形状，破坏集成方；**0.15.0 部分翻案**（见决策 3 修订）：块级构造在单行条目里不可恢复，于是解析层照旧产出「条目」，但条目内部改为保留行边界；破坏性部分写进 CHANGELOG 与 README 迁移说明，而不是继续牺牲块级质量。

## 后果

- 正面：日志里的代码、重点、出处一眼可见；危险输入与截断悬空都被收敛成可读文本；宿主零改动、集成方可选接管；0.16.0 起**版本节里的内容不再静默消失**（覆盖率 98.5%，幻影版本 0）。
- 代价：多了一层要维护的支持面（新增构造要同步 ADR/README/测试）；`renderChangelogItem` 的输出变长（`<code>`/`<a>` 等）——有逐字断言的老测试需按新输出更新；0.16.0 改了两处诊断码与 `ChangelogEntry` 形状，集成方要跟 README §5.8 的迁移说明。
- 未验证：桌面宿主里真点一次链接是否弹系统浏览器（链路已取证，点击未做）；web 认证后的 CSP 头（`curl -I` 带凭据一条即可结案）。两条都不影响本决策成立。

**更正一处不准确的早期记录**：0.14.0 那轮曾把围栏写成“整块被当成一个行内 `<code>` 吃掉”。那是把围栏字符串**直接喂渲染器**看到的假象；走真实管线（`parseChangelog`）时围栏内容是被**丢弃**的——“渲染器看起来能处理”不等于“管线里到得了渲染器”。取证要贴着真实入口，这一条比结论本身更值得记。

## 保真轮（0.16.0）：从「漂亮」到「不丢」

上表最后一行（非六类小节名、版本标题变体、顶格内容、截断）是 0.16.0 的主战场。判定用的尺子独立于被测解析器：`parseChangelogReport` 的产物按文件对照**原始文本**——内容行（非标题）里有多少能在渲染结果中找到、丢失的行落在哪一类（64 KiB 切割点之后／版本节之外／前言），并同时检查有没有**幻影版本**（产出的版本节找不到源行版本号支撑）。脚本：`.tmp/audit-fidelity-v2.mjs`（只读，`--plugins` 出逐份明细）。

| 指标 | 0.15.0 | 0.16.0 |
| --- | --- | --- |
| 插件语料（8 份 DSH 插件副本）内容行覆盖率 | 73.3% | **98.5%** |
| 全库（88 份 CHANGELOG.md）内容行覆盖率 | 7.4% | **39.8%** |
| 幻影版本 | 0 | **0** |
| 一份都显示不出的插件文件 | 1/8（`dsh-im-companion` 126 条整节丢） | **0/8** |

插件语料残留 10 行“看不到”的分类（逐行核过，不是偷懒的百分比）：

- **8 行文件前言**：首个版本标题之前的体例说明（`格式为 Keep-a-Changelog 子集：…`、`> 体例说明…`）——不是变更条目，面板只画版本节，属**声明的排除**。
- **2 条版本节之外的条目**：`dsh-mattpocock-skills-deck` 里 `## Changed` 标题下的条目（该文件没有版本节标题）——`validateChangelog` 对它报 `E_BULLET_ORPHAN` 并给行号，属**声明的丢失**。

全库覆盖率仍低的原因是第三方包：`64 KiB 切割点之后 2782 行`（超长日志，声明式截断）、`* **deps:**` 逐 commit 罗列且无版本节标题的格式、以及每类 200 条 / 单条 500 字的既有预算。这些不是本包要服务的“更新说明”形态，未列入本轮目标。

仍未做（全部归 [#116](https://github.com/FeatherHunter/dsh-plugin-update/issues/116)，且都需要先定“方言口径”）：表格画成表格、任务清单画复选框、脚注/定义列表的专有形态、emoji 短码换图、`***粗斜***` 的三重强调、缩进代码块识别成 `<pre>`、跨空行的松列表合并、第三方逐 commit 日志形态。**注意区别**：这些构造 0.16.0 起**不会再丢字**（认不出就落进 `<div class="dsh-upd-md-para">` 按原文显示），缺的是**渲染形态**，不是保真。取舍原则不变：**先保证不丢，再谈多漂亮**。

### 口径：把「保真」定成两条能跑的断言

感觉不算数，所以本轮把保真写成两条断言，可执行版本在 `tests/changelog-fidelity-116.test.mjs`（22 例）：

1. **无未声明丢失**：源文件里第一个**版本**标题之后的每条内容行，取它的签名（该行最长的字母数字连续段）——签名必须出现在渲染结果里。唯一允许不出现的，是 `validateChangelog` 已经报出来的那些（版本节之外的条目 `E_BULLET_ORPHAN`）、以及 64 KiB 与「每类 200 条 / 单条 500 字」这类**声明式截断**（面板另补一行说明，`parseChangelogReport().truncation` 把账本交出来）。
2. **幻影版本 = 0**：每个渲染出的版本节都必须能在源文件里找到对应版本号 token；解析器不许凭空造节。

尺子必须独立于被测解析器（否则「不丢」就是循环定义）：签名从**原始文本**上取，不经过解析层。文件抬头（第一个版本标题之前的体例说明）按口径不算版本节内容行，属**声明的排除**。

### 顺带补上的方言（0.16.0 后半程）

- **setext 标题**（`标题` + `===`／`---` 下划线，jimp 类日志 47 处）：先转成 ATX 形态再走同一套判据。转换**保持行数不变**——下划线那一行清空而不是删掉，`validateChangelog` 的行号才仍指向原文件。
- **分隔线** `---`／`***`：不再以字面三个短横混在正文里，渲染成 `<hr class="dsh-upd-md-hr">`（列表项后面紧跟的 `---` 不会被误判成 setext——那一行不是标题行候选）。
- **认不出的块**（HTML 注释、`<details>`、表格行、任务清单）：按原文落进 `<div class="dsh-upd-md-para">` / 近似形态——不渲染花活，但绝不静默消失。
