新增（Added）

  • 新增回归 test:issue-149（scripts/test-issue-149.cjs）：布局契约（DOM 顺序 / 上限相对视口 / 五行下限 / 无第二头行 / 弹窗恒在最上）、底栏四动作（＋开新增弹窗、×收面板、设置入口）、设置入口「成功才收面板、失败原位提示」、触发器识别与留痕字段白名单、i18n 双语。
修复（Fixed）
  • 「设置 → 模板管理」不再静默失败（#149）：旧实现只在宿主触发钮的可见文本里找「设置 / Settings」，而该钮由 settings.trigger 槽位渲染（窄栏 label 视觉隐藏、贡献缺席时退化成无可访问名的图标钮）→ 一次都没点到，面板却已先关，表现为「点开没反应」；现按 aria-label / title / 可见文本三处识别 + 类名与 aria-keyshortcuts 兜底 + 200ms×18 轮询重试（约 3.6s，宿主 actions.open 幂等）+ 设置页已开时免触发直达本插件页，成功才收面板，失败原位提示并记 remote.direct.open 留痕。
  • 修 scripts/test-issue-83.cjs 的空转守护：headSlice 的锚点（compact ? h(）正是本版删掉的紧凑头行，锚点落空后切片静默退化成「文件头 3000 字」却仍报绿；改锚新底栏铬（barNode → compactBar）并加「锚点找不到即失败」，负控验证（注入禁用词必红）有效。
变更（Changed）
  • 跟进 dsh-plugin-update 0.12.0 → 0.13.0（构建期 ensure:update-pkg 自动跟最新；lib/update.js 与 lib/client.js 同步重建，单插件 http 接线不变）。
